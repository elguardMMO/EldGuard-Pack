# EldGuard - pack de ressources du serveur

Pack de couleurs `ReShaded` adapte a Minecraft 1.20.1 pour le serveur EldGuard (MonMMO).

Base sur **ReShaded** par **DR7** (https://modrinth.com/user/DR7). Les shaders d'origine visent Minecraft 1.21.6 a 1.21.10 ; ils ont ete refaits pour 1.20.1 (terrain et particules) avec le calcul des couleurs deplace du pixel vers le sommet pour de meilleures performances.

Ce depot sert uniquement a heberger le fichier telecharge automatiquement par le serveur. Les droits du pack original restent a son auteur.
